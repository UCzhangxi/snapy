# Reader tasks (N2)

The curated reader-task list from which `tools/gen_reader_tasks.py` generates Appendix G. It was built at
tech-report `8f90b2437ea93234b1aad0254bc7e1d8fa1bbf35` from four seeds: the 95 questions of the newcomer bank
(`tools/task-map.yaml`, six split into parts), the 18 held-out NO-ENTRY tasks (two split), the 7 N6 extension
blocks and the 71 DO cards. Seeds that are the same task are merged into one row, which lists every source.

Format: one table, 5 columns, one row per line. `id` is unique. Column 4 is either a bare label `sec-...`, the
section that answers the task, or `not provided: <status>: <reason>`. Column 5 holds the reviewer's note; for an
anchored row it starts with the rendered section number. A literal `|` inside a cell is written `\|`.
